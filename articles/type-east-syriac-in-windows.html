To type East Syriac in Windows, you will need to do the following steps 1. Have a document editor installed - popular ones are MS Word, LibreOffice etc. MS Word requires a paid subscription, LibreOffice is free. 2. Download the East Syriac font you want to use (the most popular font is the East Syriac Adiabene, you can download it here). More fonts are available here. 3. Install the font by double clicking on it and following the instructions. 4. Install the Syriac Phonetic Keyboard from here. 4. Open the document editor and select the font you want to use.
